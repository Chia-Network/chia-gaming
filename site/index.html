Game rules you can rely on.

Each game has rules enforced by the Chia blockchain. Players can’t make an illegal move or claim a payout the rules don’t allow. If an opponent stops cooperating, the game can continue on-chain, with timeouts so they can’t hold it up forever.

Powered by Chia state channels.

Chia is the blockchain underneath it. State channels let players exchange signed moves without waiting for a block every turn, while keeping the blockchain’s rule enforcement available when needed. The hub helps players find each other and relays messages; it never holds their funds.

Direct competition.
No house.

Skill and strategy matter: you compete directly against another player, with no house taking the other side of the game. The players agree on the stakes, and the game’s rules determine the outcome.

Open source, from the ground up

Play it. Run it. Build on it.

The player app is a static website: HTML, JavaScript, and WebAssembly files that run in your browser. You can serve those files from any static web host, including GitHub Pages. There’s no player-app backend to run; the app connects separately to your wallet and a hub.

Download the player app and hub, host your own setup, or write a game. The source and game-writing guide are available on GitHub.
